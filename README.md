# Task 6: Excel Formulas & Functions Fundamentals

## Internship
Veda Technology — Data Analytics Track

## Objective
To practice essential Excel formulas and functions used in data analysis with sample retail sales data.

## Tools Used
- Microsoft Excel
- Sample transactional sales dataset

## Functions Covered
- VLOOKUP and XLOOKUP
- IF
- SUMIFS and COUNTIFS
- LEFT, RIGHT, LEN, UPPER, and CONCAT

## Workbook Contents
- **SalesData:** Sample retail sales data
- **FormulaPractice:** Formulas with examples and expected outputs
- **FormulaNotes:** Formula definitions and use cases
- **InterviewQuestions:** Basic interview questions and answers

## Learning Outcomes
- Practiced searching and retrieving data.
- Applied conditions and calculated totals.
- Counted records using multiple criteria.
- Used text functions to manipulate data.
- Reviewed common Excel interview questions.

## Deliverable
`Task6_Excel_Formulas.xlsx`

This task demonstrates the use of fundamental Excel formulas for everyday data analysis.
